
# 📊 Mobile Sales Analytics Dashboard

## Project Overview
End-to-End dashboard to analyze sales performance, customer behavior, and brand contribution across cities.

## Technologies & Working
- **Python (Pandas, NumPy)** – Data cleaning & preprocessing
- **MySQL** – Data storage & aggregation queries
- **Power BI** – Dashboard development & visualization
- **DAX** – KPI calculations & time intelligence
- **Insights** – Analyze sales trends, top brands, and customer patterns

## Project Structure
- data/ → datasets
- python/ → scripts
- sql/ → SQL queries
- powerbi/ → dashboard
- images/ → screenshots
- reports/ → exported reports
